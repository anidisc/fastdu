🌐 Funzionalità Remote in fastdu

A partire dalla versione 0.70.0, fastdu introduce un'architettura Client/Server per la gestione ultra-rapida di filesystem remoti tramite SSH.

Architettura: Invece di scansionare file per file tramite la rete (lento), fastdu locale avvia un'istanza di se stesso sul server remoto. Il server scansiona i dischi alla velocità locale e invia uno stream compresso di dati al client.

1. Modalità Server

Il server viene attivato con il flag --server. Non necessita di configurazione o porte aperte, poiché comunica tramite stdin/stdout.

# Esempio di avvio manuale (raramente necessario)
fastdu --server /home/utente/dati

2. Connessione dal Client

Per connettersi a un server remoto, utilizzare il flag --connect (o -c) seguito dall'URI in stile SSH:

fastdu --connect utente@server-remoto:/var/www/html

Cosa succede dietro le quinte:

  1. Il client locale apre un tunnel SSH.
  2. Esegue fastdu --server /var/www/html sul remoto.
  3. Riceve la struttura della cache compressa in tempo reale.

3. Operazioni Supportate

  • Navigazione Istantanea: Grazie allo streaming della cache, la navigazione tra le cartelle è veloce quanto quella locale.
  • Cancellazione Remota: Premendo d, il comando viene inviato al server ed eseguito localmente sul filesystem remoto.
  • Rinomina: Supportata nativamente con aggiornamento immediato della vista.
  • Ricerca Globale: È possibile cercare file su tutto il server remoto in frazioni di secondo.
Requisiti: Il binario fastdu deve essere presente nel PATH del server remoto o deve essere specificato il percorso completo nelle impostazioni.
